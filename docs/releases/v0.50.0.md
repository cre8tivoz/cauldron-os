# Cauldron OS v0.50.0

Cauldron OS v0.50 proves more of the handoff before you leave Cauldron. This release adds deterministic verification, a generated launch checklist for every exported project, and an optional design package derived from the selected design reference plus prototype output.

## Highlights

### Verify builds before handoff

Cauldron can now run a deterministic verification pass against either a build workspace or an exported project folder. The result reports manifest, static, command, and accessibility checks with explicit `passed`, `failed`, `skipped`, and `not_configured` states, then rolls them up into `PASS`, `PASS WITH WARNINGS`, or `BLOCKED`.

### Send findings back into the build agent

The Build stage now exposes verification state directly in the UI and can feed failing findings back into the local XML build path for a fix pass instead of leaving the user to restate the problems manually.

### Generate `launch-checklist.md` with every handoff

Every exported project package now includes a human-readable runbook covering commands, required environment variables, verification results, known warnings, human follow-ups, and a plain-English “you’ll know it worked when...” check.

### Optionally export a design package

Handoffs can now include `docs/design.md` and `docs/design.html`. The package is derived from the chosen design reference and prototype output, and mirrors the same inferred tokens in machine-readable and human-readable forms.

## Validation

- Full smoke suite including new verification and design export coverage
- Existing handoff and scaffold export smoke tests extended for launch checklist assertions
- Targeted lint on release-touched files
- Manual verification UI review and exported package inspection

## Notes

- BuilderOS remained reference-only for release shape and deliverables. Cauldron does not install BuilderOS or add a second orchestration layer.
- Blueprint remains the canonical contract. Verification, checklist, and design-package files are derived artefacts.
